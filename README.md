**Tools:** Microsoft Excel  
**Skills:** Data cleaning, exploratory analysis, KPI tracking, dashboard design

### 📏 [Stationery Store Sales Dashboard](./02_stationery_store_sales)
**Tools:** SQL, Looker Studio
